# 動画の時系列一覧

「動画一覧」に概要解説・詳細解説を表示します。完成日時の新しい順が既定で、日付・時刻は閲覧PCのタイムゾーンにかかわらず日本時間です。サムネイル、論文名、学会、受賞、長さ、容量とダウンロードを同じ行に表示します。旧方式の全章まとめ・章別動画は通常の画面には表示しません。

同じ教材・動画種別の再出力は、最新の完成版を表示し、過去のMP4は「以前の版」に保持します。新しい脚本で作った別教材は独立した動画です。短いプレビューや作成途中の出力は完成一覧に入りません。検索、古い順への変更、動画再生、YouTube用タイトル・説明文のコピー、英語練習への移動にも対応します。

一覧は読み取り専用の `GET /api/videos` を使います。本文、生成マニフェスト、音声照合の記録は取得せず、ダウンロード可能なMP4の公開用メタデータを返します。完成日時は新しい出力では `completed_at` に保存し、既存MP4はファイルの更新時刻を使います。サムネイルやタイトルの編集で一覧の並び順は変わりません。

画面は次の5つに整理しています。

- **動画一覧**：完成した概要・詳細動画の再生、ダウンロード、投稿情報。
- **動画を作る**：自動選定、保存済みの論文を指定、arXiv・PDFの取り込み。進捗はここに集約し、脚本・プレビュー・サムネイル候補は必要なときに開きます。受賞情報と処理一覧は折り畳んで表示します。
- **英語練習**：教材検索、完成した場面の練習、今日の復習。学習画面には制作パネルや旧MP4出力の操作を表示しません。
- **論文を探す**：日本語のテーマ検索、題名・要約、選んだ論文からの動画作成。
- **設定**：夜間02:00運転、対象分野、受賞優先、ローカルモデル。旧章教材の自動探索設定は撤去しました。

手動の取り込みも現在の `paper-story-1` に統一しました。arXiv登録は `POST /api/papers/import` に `create_video: true` を、PDFは `POST /api/papers/upload` のフォームに `create_video=true` を指定します。取り込み後、概要・詳細の2本を作り、再試行は同じプロジェクトを再利用します。旧API利用との互換性は保ち、停止済みの旧教材を再開しません。取り込みの完了先は `GET /api/jobs` の小さな `paper_id` フィールドで取得できます。

- `pytest tests/test_video_library.py tests/test_api.py tests/test_video.py tests/test_video_release.py -q`
- フロントエンドのビルドと `npm run test:e2e`
- プロジェクトのルートで `.tools/node/bin/node scripts/video_library_browser_acceptance.mjs`

同日、ユーザーの依頼でLoRAの概要・詳細版より前に作った旧方式の教材5件をアーカイブしました。古い練習カード・全章まとめ・章別動画・復習の枠は通常の一覧から外します。データや録音・MP4は削除せず、停止中ジョブも再開しません。新しい教材作成でアーカイブ済みの古い未完了教材を再利用せず、古い章の書き出しも自動追加しません。

`.venv/bin/python scripts/archive_legacy_lessons.py` は対象の確認だけを行います。`--apply` を付けると、最初の `paper-story-1` 教材より古い別形式の教材に `archived` と日時・理由を保存します。再実行は重複して変更しません。アーカイブ後も既存IDで教材やファイルを取得できます。

追加のUI整理では、英語教材を論文ごとにまとめ、概要・詳細を同じ枠から選ぶ形にしました。14教材は7論文の枠として表示します。同じ論文・種別で作り直した以前の教材は折り畳み、各教材のID・録音への移動を維持します。

保存済みの論文を選ぶ画面では、現在の教材がある論文を先に表示します。参考文献や未作成の論文は「参考文献・未作成の論文も表示」で追加でき、題名とarXiv IDで絞り込めます。制作・投稿情報・ダウンロードの操作名も日本語にそろえました。狭い画面では上部に5つのメニュー名を表示し、横にはみ出さないことを確認しました。
