# 英語の詳細解説と日本語解説

新しい標準構成は `deep_dive`（英語・詳細解説）→ `deep_dive_ja`（日本語解説）です。英語版を先に完成させて公開可能にし、その確認済み脚本・原図・数式から日本語版を作ります。新規の概要編は作成しません。旧版の動画、教材、録音は保持します。

## 作成と再開

`POST /api/papers/{id}/video-projects` の本文を省略すると2本を作ります。`modes` で英語版だけを選ぶこともできます。日本語版の指定には必ず英語版を先行させます。`overview` はAPIで422になります。既存の旧プロジェクトを処理・試験するための内部互換オプション `legacy=True` はAPIに公開しません。

取得API、動画一覧、動画マニフェストには `language`、`subtitle_languages`、`voice_profile` を記録します。言語がない旧データは英語と英日字幕として扱います。動画一覧の日本語版には、同じプロジェクトの `english_lesson_id` を返します。日本語版の内部教材は `learning_enabled=false` とし、英語練習・録音評価・復習に混入させません。

本文・原図・確認済み根拠・対応する英語の構成を再利用できます。正常に読み終えた新形式の読み取りグループも確認して再利用します。日本語の会話・音声・時刻は新しく保存します。言語、モデル重みの固定情報、声設定、レンダラーがキャッシュの識別に入ります。タイトルの表示ラベル変更だけで作成中プロジェクトを重複登録しません。

停止・再開・録音優先・最大3回の修正は既存ジョブを使います。日本語台本が直らなければ、確認済みの日本語字幕を発話の代替案として使います。科学的な条件・数量を残し、認識の不一致や省略理由は記録します。生成中に新しい日本語台本の全体を最初からやり直す仕組みではありません。

## 日本語の声と字幕

導入済みのQwen3-TTS VoiceDesignをBF16で使います。Mayaは落ち着いた女性、Aidenは好奇心のある男性の標準日本語です。声の指示文・版・基本seedを役ごとに固定します。字幕用 `text` と読み上げ用 `spoken_text`、専門語の `readings` を分けて保存します。

Qwen3-ASRとForcedAlignerにJapaneseを指定します。日本語は文字単位の誤り率、表記ゆれ、重要な数量、否定で照合し、英語用の空白区切りのWERは使いません。字幕と図の切り替えは日本語音声の時刻から作り直します。原図は書き換えません。

字幕は日本語だけを動画へ直接入れます。1080pで64pxを基本、54pxを下限とし、2行を優先、必要なら3行にします。長文は句や文の境界で時刻付きの字幕に分け、全文を残します。キャラとの重なりや画面外へのはみ出しは認めません。日本語版には英語SRTを作らず、焼き込みの英語字幕イベントも作りません。

英語版の声、英日字幕、一文クリップ、英語表現、理解確認、録音・評価・復習は維持します。タイトル、サムネイル、MP4名、説明文は、英語版を「英語・詳細解説」、日本語版を「日本語解説」と区別します。学会・賞名は確認済みの情報だけを入れ、説明文にURLを入れません。

## 確認

```bash
.venv/bin/pytest -q tests/test_japanese_story.py tests/test_story.py tests/test_storyboards.py tests/test_video.py tests/test_video_review.py tests/test_thumbnails.py tests/test_nightly.py tests/test_pipeline_health.py tests/test_practice_priority.py
PATH="$PWD/.tools/node/bin:$PATH" npm run test:e2e --prefix frontend
```

内部検証ジョブ `japanese_voice_probe` は、男女の日本語音声、数字、否定、専門語、単語時刻を実機で確認します。`scripts/check_japanese_video.py` は保存済みの検証音声とRoboJEPAの確認済み原図から、外部通信なしで1080pの字幕・口パク確認用MP4を作ります。この短い確認動画は完成した論文解説ではなく、通常の動画一覧へ登録しません。

実測記録は `data/evaluation/japanese-details-probe/`、移行記録は `data/evaluation/detail_languages_migration.json` に保存します。完成した2本には既存の実動画評価ジョブが接続され、日本語版は日本語の初学者・実務者・数式が苦手な視聴者の3ペルソナで評価します。これらはローカルAIによるシミュレーションで、人による視聴試験ではありません。

02:00（日本時間）の自動選定も新構成を使います。以前停止した旧教材は再開しません。YouTubeへの投稿と公開は手動です。
