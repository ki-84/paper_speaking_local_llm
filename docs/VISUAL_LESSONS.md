# 図を見ながら学ぶ教材

新しい教材形式は `paper-visual-2` です。「Make a visual lesson」または新たな教材作成から使用します。旧版の停止ジョブは再利用せず、既存の会話・音声・録音を保存したまま別の教材を作ります。同じ論文・版・モデルで検証済みの読解ノートは再利用できます。会話と音声は新しく生成します。

外部ネット接続は論文・モデル・依存関係の取得に利用できます。図の理解、図の構成、会話、翻訳、音声、録音評価の推論はLinux内の無料で利用できるローカルモデルで行います。有料APIやクラウド画像生成は使いません。原本とモデルを保存した後の生成は外部推論に依存しません。

## 保存する工程

1. PDFの図・表番号、キャプション、ページ、切り出し位置を記録し、ベクター図も領域を描画してPNGにします。
2. 根拠ノートと章構成を決めます。
3. 章ごとに原図を最大2点、補助図を最大1点選びます。ローカルモデルの構造化データから固定のSVGテンプレートで補助図を作り、ローカルChromiumと日本語フォントでPNGにします。
4. 図と原ページ・出典、英日説明を照合します。モデルが返したHTMLやコードは実行しません。図の画像、ハッシュ、モデル設定、検証と修正の履歴を保存します。
5. 図を説明する会話を書き、出典との内容確認と、図の位置・ラベル・強調領域との対応確認を行います。
6. 理解確認の問題・ヒント・回答例・採点項目も原文と照合します。採点対象はその章で説明した内容に限定し、質問文は一問ずつ短くします。
7. 音声生成とASR照合を行い、日本語訳は8項目ずつ生成・意味確認して保存します。数量・否定・比較・適用範囲・掛け算と累乗を確認し、問題のある訳だけを修正します。確認した英日文字列のダイジェストが変われば再確認が必要です。全項目が通過してから章を公開します。

図の計画・確認には3回の試行上限があります。理解確認と日本語の意味確認も未解決のまま3回に達した場合は保留します。解決しない問題はジョブに理由を表示し、章を保留します。図ファイルが失われた、会話と図の対応が変わった、検証後に画像が変わった場合も未確認の章を完成扱いにしません。検査が「問題なし・修正不要」を修正項目に入れるなど、判定自体が矛盾する場合も公開せず再確認します。図の用語・条件の妥当性にはモデルの判断も含まれるため、原図と原文を開いて確認できます。

選んだ図の説明が会話から抜けた場合は、その図の説明を追加してから章全体を検証します。図番号を一度述べただけでは説明済みにしません。明確な文末で二文に分かれる出力は、言葉・出典・図の指定を保って一文ずつに分けます。明示された原図番号と表示キーが違う場合は、選択済みの対応する原図へ結び直し、その変更も記録します。未選択の図番号は自動で捏造せず検証エラーにします。文章だけの修正で図の指定が省略された場合は元の指定を保持し、会話と画像の再検証を行います。原図を使う内容検証では、画像と出典番号の対応も明示します。

PNGは一時ファイルへの出力が完了してから置き換えます。途中停止した画像を完成画像として再利用しません。写真パネルのPDF内部サイズと表示範囲が違うなど、切り出し範囲を確定できない場合は原ページを使います。

`visual_assets` は原図・補助図・仮の例を区別します。原図の元画像とキャプションを書き換えず、別の英日説明を付けます。補助図は原文の出典IDを持ちますが、それ自身を論文の証拠として `sources` に登録しません。図のPNG/SVGは `data/visuals/`、抽出画像は `data/papers/<id>/figures/` に保存し、通常のバックアップにも含めます。

## 学習画面

「Visual lesson」の教材を開くと、文の `visual.key` と `focus` に従って図と強調箇所を表示します。同じ図を説明する連続文には同じキーを割り当てます。補助図の箱・矢印、確認できた原図の領域を強調できます。

「Auto · 自動表示」で再生・前後移動に連動します。短い相づちなど、次の図の指定がない文でも直前の図を保ち、強調だけを外します。図一覧の選択または「Pin · この図を固定」で固定し、「Auto」で会話の図に戻ります。選択と再生位置は再読み込み後にも復元します。章が切り替わると自動表示へ戻ります。「Enlarge · 拡大」で開くと、100〜300%のズーム、スクロール、注目領域への移動ができます。原図の「Original page · 原ページ」で掲載ページを開けます。英日説明は最初から併記します。PCの広い画面では図と会話・録音ボタンを横に並べます。

## 確認方法

```bash
.venv/bin/python -m pytest -q tests/test_visuals.py
PATH="$PWD/.tools/node/bin:$PATH" npm --prefix frontend run test:e2e
.tools/node/bin/node scripts/visual_acceptance.mjs <ready-visual-lesson-id>
```

Python試験はベクター、写真の複数パネル、PDFのみ、ページへのフォールバック、重複・中断再開、失敗時の保留、会話変更後の再確認、任意ファイルの指定防止を含みます。ブラウザ試験では専用の試験教材を使います。`visual_acceptance.mjs` は実際の生成済み章で音声の終了に伴う図の切替、英日表示、固定と再読み込み、原ページ、拡大を試し、学習位置を戻します。画像とJSON結果は `data/evaluation/visual-*` に残します。物理的なMacでの試験とは区別します。

定期探索と他の停止中教材はこの機能の導入では再開しません。検証用LoRAだけを明示して作成します。

導入時の実教材は、LoRAの「Visual lesson · 図付き教材」の第1章（126文・約8分）です。第1章を試せる状態で続きは停止しています。定期探索は無効、日次教材化上限は0のままです。検証結果は [検証記録](VERIFICATION.md) を参照してください。
