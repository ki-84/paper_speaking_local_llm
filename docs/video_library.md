# 動画の時系列一覧

My libraryの最初に「作成した動画」を表示します。完成日時の新しい順が既定で、日付・時刻は閲覧PCのタイムゾーンにかかわらず日本時間です。サムネイル、論文名、概要解説／詳細解説／全章まとめ、学会、受賞、長さ、容量とダウンロードを同じ行に表示します。

同じ教材・動画種別の再出力は、最新の完成版を表示し、過去のMP4は「以前の版」に保持します。新しい脚本で作った別教材は独立した動画です。短いプレビューや作成途中の出力は完成一覧に入りません。全章まとめ・章別動画の選択肢は、表示対象に該当する動画がある場合に出ます。検索、古い順への変更、動画再生、YouTube用タイトル・説明文のコピー、英語練習への移動にも対応します。

一覧は読み取り専用の `GET /api/videos` を使います。本文、生成マニフェスト、音声照合の記録は取得せず、ダウンロード可能なMP4の公開用メタデータを返します。完成日時は新しい出力では `completed_at` に保存し、既存MP4はファイルの更新時刻を使います。サムネイルやタイトルの編集で一覧の並び順は変わりません。

既存の教材・録音・動画は保持します。保存済みの論文を選ぶ制作画面は「保存済みの論文から動画を作る・脚本を見る」を開いて使います。夜間制作の操作は「昨夜の動画」、練習教材は「英語練習教材」にあります。

検証:

- `pytest tests/test_video_library.py tests/test_api.py tests/test_video.py tests/test_video_release.py -q`
- フロントエンドのビルドと `npm run test:e2e`
- プロジェクトのルートで `.tools/node/bin/node scripts/video_library_browser_acceptance.mjs`

最後の検証は実際のLAN画面、日付順、過去版の保持、MP4のRangeダウンロード、サムネイル、完成動画の再生、390px表示、ジョブを起動・再開しないことを確認し、`data/evaluation/video-library-browser.json` と画面画像を保存します。

2026年10月4日のサービス反映時に、全体動画13本（概要6本、詳細6本、全章まとめ1本）と章別動画19件の最新版を確認しました。全体動画の過去版5本も含む18個の実MP4でRange取得を確認し、最新のMuninn動画をブラウザで再生しました。API・書き出し関連33テスト、画面20テスト、ビルド、実LANと390px表示の確認を通過しました。[検証記録](../evaluation/video_library_acceptance.json)を保存しています。

同日、ユーザーの依頼でLoRAの概要・詳細版より前に作った旧方式の教材5件をアーカイブしました。古い練習カード・全章まとめ・章別動画・復習の枠は通常の一覧から外します。データや録音・MP4は削除せず、停止中ジョブも再開しません。新しい教材作成でアーカイブ済みの古い未完了教材を再利用せず、古い章の書き出しも自動追加しません。

`.venv/bin/python scripts/archive_legacy_lessons.py` は対象の確認だけを行います。`--apply` を付けると、最初の `paper-story-1` 教材より古い別形式の教材に `archived` と日時・理由を保存します。再実行は重複して変更しません。アーカイブ後も既存IDで教材やファイルを取得できます。

アーカイブ前後で旧教材の180章、31動画出力、72録音、48復習記録の件数が同じことを確認しました。旧カードが通常一覧から消え、完成済みの概要・詳細動画13本と新方式の練習教材14件が表示され、停止中の旧ジョブ3件は停止を維持しています。関連27テスト、画面20テスト、ビルドとLAN確認を通過しました。[アーカイブの検証記録](../evaluation/legacy_library_archive_acceptance.json)を保存しています。
