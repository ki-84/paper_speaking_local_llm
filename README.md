# PaperSpeak Linux

論文を読み、二人のやさしい英語の会話で学び、自分の声で説明する個人用スタジオです。LinuxでAIと保存処理を行い、LANのPCからHTTPSで利用します。

## このPCで開く

```bash
cd /home/kuwabara/devwork/paper_speaking_linux
./studio start
./studio access
```

ブラウザで **https://192.168.10.112:8443** を開きます。初回は `studio access` が示す **root.crt だけ**を利用PCにコピーして信頼してください。[LAN・証明書の手順](docs/LAN.md)を参照してください。秘密鍵や `credentials.json` は他PCにコピーしません。LANでパスワードなしにする場合は `./studio auth-off`、戻す場合は `./studio auth-on` を実行します。パスワードを外すと、サイトに接続できるLAN内の端末から教材・録音・設定を操作できます。

2026年10月3日、論文ごとに独立した解説編・詳解編を作る `paper-story-1` を追加しました。ライブラリまたは学習画面の「解説・詳解動画を作る」から、C1英語の会話、英日字幕、図解、英語練習をまとめて作成します。[使い方と復旧手順](docs/story_video_pipeline.md)を参照してください。既存の教材は保持し、旧教材向けの定期探索と以前停止した教材は再開しません。YouTubeへのアップロードと公開は手動です。

設定の「夜間に解説・詳解を自動作成」では、毎日02:00（日本時間）にAI・LLM・ロボティクスの注目論文を選び、2本の動画と英語教材を作成できます。Maya・Aidenの驚き顔、大きな日本語、ローカルFLUXの内容図を使ったサムネイルを3案ずつ用意します。完成した動画はライブラリの「昨夜の動画」から使えます。長引いても時刻では打ち切らず、翌日は新規作成を抑えて続きを進めます。[夜間運転・サムネイルの仕様](docs/nightly_video_pipeline.md)を参照してください。

論文の選定は、最近2開催年のAI・ロボティクスの主要学会で、公式に優秀論文賞・Test of Time賞を確認できた未動画化の論文を優先します。Test of Time賞は古い論文も対象とし、発表年と受賞年を区別します。賞名・開催年・公式リンクを表示し、受賞論文に適した候補がない場合は新着論文に切り替えます。[受賞優先の選定と検証](docs/award_selection.md)を参照してください。

## できること

- arXiv URL/ID・PDFから、原文とページ画像、根拠、構成、対話、内容確認、音声を段階的に作成します。完成した章から学べます。
- 新形式では論文の原図と英日併記の補助図を先に用意し、その図を説明する会話を作ります。再生・文の移動に合わせて図を切り替え、拡大、原ページ、手動選択と固定も使えます。旧教材は保持します。[図付き教材の仕様と確認手順](docs/VISUAL_LESSONS.md)を参照してください。
- 完成した図付き章は、図・英語音声・動画に直接入る英日字幕を含むYouTube向けMP4へ自動変換します。全章完成後に一本のMP4も作ります。Googleアカウントを接続した場合だけ、完成版をYouTubeへ非公開で自動アップロードできます。[動画と接続手順](docs/VIDEO.md)を参照してください。
- AidenとMayaの会話を全体・章・一文で再生し、速度・字幕・練習する役を選べます。標準は自然な会話速度の1倍で、ゆっくり・速めにも切り替えられます。以前のRyan音声は検証後にMayaへ置き換え、元の音声も履歴に残します。
- 新しい章は英語音声と日本語訳の両方が完成してから公開します。訳は最初から表示され、ボタンで隠せます。会話文、設問、ヒント、用語説明をローカルモデルで訳し、英語原文と出典も残します。既存章の未翻訳部分は起動時に自動で補います。
- 録音を先に保存し、単語・音素・速さ・間・強勢を別々に表示します。違って聞き取られた単語には、英語と日本語の説明、練習する音、お手本と自分の声の短い聞き比べを表示します。同じ発音の表記差は発音ミスとせず、音声認識や音素判定の不確かさを明示します。無音は採点しません。
- 章末で自分の言葉による説明を練習し、内容と英語表現を分けて確認します。復習を1・3・7・14日後に提示します。
- 定期探索を有効にした場合、毎日03:00（日本時間）にarXivを収集します。初回30日、以降差分です。最大10候補の本文を読み、推薦理由と注意点を作ります。適した論文だけ設定した上限まで教材化します。現在は定期探索を無効、日次教材化の上限を0本にしています。
- 「論文を探す」では、読みたいテーマを日本語で入力できます。ローカルモデルが検索語を作り、arXivの候補の題名と要旨を日本語で表示します。候補を選ぶと本文検証から教材作成を開始します。定期探索のおすすめも日本語の題名・要旨・理由・注意点で読めます。原題と英語要旨はカードから確認できます。
- 処理を停止・再開・再試行できます。ブラウザを閉じても処理と履歴は残ります。録音評価は教材生成の区切りに優先して実行します。
- 音声は表記差（数字の読み方や数式の読み方など）を正規化して文ごとに確認します。ローカルLLMの言い換えでも確認できない文、根拠のない数値を含む文、図と食い違う文は、その文だけを除いて章を再確認します。内容確認や理解問題の修正を使い切った場合も、問題の文・設問だけを除外して残りを進めます。補助図が直らなくても確認済みの原図があれば、その原図で章を続けます。すべての章を試した後に保留が残った場合は、出典と構造を確認できた会話だけを残す短縮版へ自動で切り替えます。確認できる会話も残らなければ、原文を確認するよう促す最短の章を作ります。省略した内容と理由は保存し、画面に注意を表示します。全章動画は全章完成後に作ります。

## 構成

React/TypeScript + FastAPI + SQLite WAL + 独立ワーカー + Caddy。推論はloopbackに限定し、ブラウザへの入口はCaddyの8443番です。論文・モデルの取得を除き、AI処理で外部サービスを呼びません。

論文解析、英語教材、日本語訳、音声生成、録音評価はこのLinux上のモデルで実行します。日本語訳にも外部の翻訳APIは使いません。自動論文探索にはarXivへの通信が必要です。

論文: Qwen3.8-27B Q8/Q6とMuse-Glimmer-30B Q6を比較し、実教材の修正結果も踏まえ、現在はQwen Q8を暫定採用しています。[採用理由と限界](evaluation/model_decision.json)を保存しています。音声: Qwen3-TTS 1.7B CustomVoice（Aiden）とVoiceDesign（Maya）、ともにBF16。認識: Qwen3-ASR 1.7BとForcedAligner。音素: Wav2Vec2。文強勢: WhiStress。モデルを切り替えてGPUを共有します。他アプリのGPUプロセスは停止しません。

モデルの固定revisionとSHA-256は [models.lock.json](models.lock.json)、Pythonの固定バージョンとハッシュは [locks/](locks/)、ブラウザ依存関係は [package-lock.json](frontend/package-lock.json) に保存します。
