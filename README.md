# PaperSpeak Linux

論文を読み、二人のやさしい英語の会話で学び、自分の声で説明する個人用スタジオです。LinuxでAIと保存処理を行い、LANのPCからHTTPSで利用します。

## このPCで開く

```bash
cd /home/kuwabara/devwork/paper_speaking_linux
./studio start
./studio access
```

ブラウザで **https://192.168.10.112:8443** を開きます。初回は `studio access` が示す **root.crt だけ**を利用PCにコピーして信頼してください。[LAN・証明書の手順](docs/LAN.md)を参照してください。秘密鍵や `credentials.json` は他PCにコピーしません。LANでパスワードなしにする場合は `./studio auth-off`、戻す場合は `./studio auth-on` を実行します。パスワードを外すと、サイトに接続できるLAN内の端末から教材・録音・設定を操作できます。

2026年9月26日の実機確認では、LANからパスワードなしで開けること、LoRA教材の英語・日本語・原文をブラウザで併せて表示できることを確認しました。完成章は画面から利用できます。従来の完成章は起動後に順次翻訳するため、訳がそろうまでは英語を表示します。残りの章と自動探索の候補選考は処理を続けています。72時間の観測と、物理的に別のPCでのマイク試験は未完了です。最新の区別は[検証記録](docs/VERIFICATION.md)に残します。

## できること

- arXiv URL/ID・PDFから、原文とページ画像、根拠、構成、対話、内容確認、音声を段階的に作成します。完成した章から学べます。
- AidenとMayaの会話を全体・章・一文で再生し、速度・字幕・練習する役を選べます。標準は自然な会話速度の1倍で、ゆっくり・速めにも切り替えられます。以前のRyan音声は検証を通った文からMayaに置き換え、元の音声も履歴に残します。
- 新しい章は英語音声と日本語訳の両方が完成してから公開します。訳は最初から表示され、ボタンで隠せます。会話文、設問、ヒント、用語説明をローカルモデルで訳し、英語原文と出典も残します。既存章の未翻訳部分は起動時に自動で補います。
- 録音を先に保存し、単語・音素・速さ・間・強勢を別々に表示します。不確かな音は断定せず、無音は採点しません。
- 章末で自分の言葉による説明を練習し、内容と英語表現を分けて確認します。復習を1・3・7・14日後に提示します。
- 毎日03:00（日本時間）にarXivを収集します。初回30日、以降差分です。最大10候補の本文を読み、推薦理由と注意点を作ります。適した論文だけ最大1本を教材化します。
- 処理を停止・再開・再試行できます。ブラウザを閉じても処理と履歴は残ります。録音評価は教材生成の区切りに優先して実行します。

## 構成

React/TypeScript + FastAPI + SQLite WAL + 独立ワーカー + Caddy。推論はloopbackに限定し、ブラウザへの入口はCaddyの8443番です。論文・モデルの取得を除き、AI処理で外部サービスを呼びません。

論文解析、英語教材、日本語訳、音声生成、録音評価はこのLinux上のモデルで実行します。日本語訳にも外部の翻訳APIは使いません。自動論文探索にはarXivへの通信が必要です。

論文: Qwen3.8-27B Q8/Q6とMuse-Glimmer-30B Q6を比較し、実教材の修正結果も踏まえ、現在はQwen Q8を暫定採用しています。[採用理由と限界](evaluation/model_decision.json)を保存しています。音声: Qwen3-TTS 1.7B BF16。認識: Qwen3-ASR 1.7BとForcedAligner。音素: Wav2Vec2。文強勢: WhiStress。モデルを切り替えてGPUを共有します。他アプリのGPUプロセスは停止しません。

モデルの固定revisionとSHA-256は [models.lock.json](models.lock.json)、Pythonの固定バージョンとハッシュは [locks/](locks/)、ブラウザ依存関係は [package-lock.json](frontend/package-lock.json) に保存します。
