# 学会の受賞論文を中心とする夜間選定

2026年10月3日に実装・実機確認し、設定を有効にした。次回の夜間選定（10月4日02:00、日本時間）から適用する。

「最近」は現在・前年の2開催年を対象とする。現時点では2026年と2025年。AI側はICLR・ICML・NeurIPS・AAAI、ロボティクス側はRSS・ICRA・CoRL・IROSの公式サイトを確認する。開催前や結果未掲載の学会は受賞を推測しない。翌年には自動で対象の開催年が進む。

公式のBest/Outstanding研究論文賞を優先し、学生論文賞・システム論文賞・分野別の研究論文賞も対象にする。最終候補、Honorable Mention、Runner-up、Test of Time・Classic、ポジション論文賞、発表・デモ・競技・査読者の賞はこの優先枠に入れない。委員会の解説文に出てくる関連論文も、受賞者と取り違えない。

受賞の確認は公式ページの見出し、受賞者欄、表、Winnerマークから行う。ローカルLLMの記憶や論文要約から受賞を判定しない。公式リンク、開催年、賞名、確認時刻、原ページのSHA-256を保存する。外部通信は公式ページと論文の取得に使い、科学的内容の評価・教材・動画のAI処理は従来どおりローカルで行う。

取得先はarXivを検索し、句読点・大小文字などを整えた題名の完全一致で確認する。同名の論文が複数ある場合や取得先が一致しない場合は採用せず、理由を残して次へ進む。受賞論文の公開日が古くても最近の受賞なら候補になる。受賞していない新着論文には7日・30日の公開日条件を適用する。

受賞候補を先に最大10候補へ入れ、上位候補の本文を読み、説明の面白さと内容の根拠を確認する。適した受賞論文があるときは、人気や新しさだけで非受賞論文に入れ替えない。適した受賞論文がない場合には新着から選び、切り替えた理由を表示する。既に動画化したarXivの同じ論文は、改訂版も除外する。賞や人気は内容が正しいことの証明として扱わない。

Settingsの **最近のAI・ロボティクス学会の優秀論文賞を優先する** で変更できる。開始時の設定を各夜間実行に保存するため、処理の途中で別の基準に変わらない。ライブラリの「昨夜の動画」には選ばれた論文の賞名・開催年・公式リンクを出し、「選定・作成の記録」には確認した学会と取得できなかった情報を残す。02:00の運転と停止中の旧教材は従来の設定を維持する。
